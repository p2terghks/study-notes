R01 · 로그인 실패 반복

같은 시나리오·주체별 실패 시각 t부터 60분 뒤까지의 실패 수를 각각 계산하고 최댓값을 선택합니다. 3~4회는 medium, 5회 이상은 high입니다. 시간 결측값은 제외합니다. 출력 시각은 집중 구간이 아니라 그룹 전체 최초 실패입니다.

R/03_detect.R · 32–47행
32rule_login_failure_burst <- function(ev, threshold = 3, window_min = 60) {33  ev |>34    filter(event_name == "ConsoleLogin", login_result == "Failure", !is.na(event_time)) |>35    group_by(id, technique, principal) |>36    summarise(37      n_total = n(),38      # 각 실패 시각 t에서 [t, t + window] 안에 들어오는 실패 수의 최댓값39      n       = max(vapply(event_time, \(t) sum(event_time >= t & event_time <= t + window_min * 60), numeric(1))),40      event_time = min(event_time),41      source_ip  = paste(unique(source_ip), collapse = ","),42      event_name = "ConsoleLogin", .groups = "drop") |>43    filter(n >= threshold) |>44    mutate(severity = if_else(n >= 5, "high", "medium"),45           detail = sprintf("%d분 안에 콘솔 로그인 실패 %d회 (전체 실패 %d회)", window_min, n, n_total)) |>46    finalize()47}

R02 · 짧은 시간의 IP 변경

ConsoleLogin 중 Root/IAMUser와 IPv4 모양의 출발지, 유효한 시간만 선택합니다. 시간순 정렬 → lag()로 직전 IP·시간 읽기 → 다른 IP이며 0~10분 차이면 탐지합니다. 성공·실패 로그인 모두 대상이며 Root는 high, IAMUser는 medium입니다. VPN 이동 등 정상 활동도 검토해야 합니다.

R/03_detect.R · 51–64행
51rule_multi_ip <- function(ev, window_min = 10) {52  ev |>53    filter(event_name == "ConsoleLogin",54           user_type %in% c("Root", "IAMUser"), str_detect(source_ip, IPV4), !is.na(event_time)) |>55    arrange(id, principal, event_time) |>56    group_by(id, technique, principal) |>57    mutate(prev_ip = lag(source_ip),58           gap = as.numeric(difftime(event_time, lag(event_time), units = "mins"))) |>59    ungroup() |>60    filter(!is.na(prev_ip), prev_ip != source_ip, gap >= 0, gap <= window_min) |>61    mutate(severity = if_else(user_type == "Root", "high", "medium"),62           detail = sprintf("%.1f분 간격으로 IP 변경 (%s -> %s)", gap, prev_ip, source_ip)) |>63    finalize()64}

R03 · MFA 없는 로그인 성공

ConsoleLogin + Success + MFAUsed=No + Root/IAMUser 네 조건을 모두 만족해야 합니다. Root는 high, IAMUser는 medium입니다. MFA 필드 누락을 No로 간주하지 않으며 페더레이션 역할은 제외합니다.

R/03_detect.R · 68–75행
68rule_login_without_mfa <- function(ev) {69  ev |>70    filter(event_name == "ConsoleLogin", login_result == "Success", mfa_used == "No",71           user_type %in% c("Root", "IAMUser")) |>72    mutate(severity = if_else(user_type == "Root", "high", "medium"),73           detail = sprintf("MFA 없이 %s 콘솔 로그인 성공", user_type)) |>74    finalize()75}
