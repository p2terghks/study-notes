무엇을 하나요?

사용자가 준비한 CloudTrail JSON 파일에서 ConsoleLogin 이벤트만 찾아 시간·사용자·IP·성공/실패를 보여주고 CSV로 저장합니다. MFA 없는 로그인·IP 변화·실패 횟수에 대한 별도 경고는 만들지 않습니다.

JSON 파일 → 이벤트 목록 → ConsoleLogin 선택 → 4개 열의 표 → CSV

실행

Rscript -e 'install.packages("jsonlite")'
Rscript login_records.R 로그.json
Rscript login_records.R 로그.json 결과.csv

추출 뒤 실패 기록을 UTC 날짜별·시간대별 막대그래프로 볼 수 있습니다. 파일 다운로드는 하지 않습니다. AWS 계정의 콘솔 로그인 CloudTrail 이벤트가 포함된 파일을 입력하세요. AWS CLI나 SDK를 호출하지 않습니다.

공개 테스트 로그 90건 실행 예시

로그인 90건 중 실패 82건(중복 포함), 시각 누락·해석 실패 0건입니다. 원본 합본의 eventID 중복 제거본은 총 43건(실패 39건)이므로 아래 수치를 독립적인 로그인 시도 수로 단정하지 마세요.

출처: Splunk attack_data 공개 테스트 로그. 그림에는 집계 건수만 표시하며 개별 사용자·IP는 포함하지 않았습니다.

검증과 범위

가상 데이터로 실제 R 실행과 CSV 저장을 확인했습니다. Records·배열·단일 이벤트·NDJSON·빈 파일·로그인 없는 파일·잘못된 JSON을 검사했고, 성공/실패 유지·시간 정렬·ARN 대체·누락값도 확인했습니다.

이 프로그램은 ConsoleLogin 기록 추출기입니다. 실제 공격 판정이나 탐지 성능 평가는 수행하지 않습니다. 파일 전체를 메모리에 읽으므로 대용량 스트리밍 도구가 아닙니다. 동일 이벤트 중복 제거는 하지 않습니다.
