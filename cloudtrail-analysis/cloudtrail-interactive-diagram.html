로그인 실패 반복 → 짧은 시간의 IP 변화 → MFA 없는 로그인 성공을 분석합니다. 시나리오 네 개는 aws_login_failure, aws_console_login_multiple_ips, aws_login_sfa, aws_concurrent_sessions_from_different_ips입니다.

실행 상태와 결과 해석

수정한 R 코드 문법 검사는 통과했습니다. 현재 실행 환경에는 tidyverse·jsonlite·lubridate·rmarkdown이 없어 실제 데이터 파이프라인과 HTML 보고서의 재실행 결과는 아직 없습니다. 과거 24/24·151건 결과는 새 버전 결과로 사용하지 않습니다.
