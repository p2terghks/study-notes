무엇을 하나요?

사용자가 준비한 CloudTrail JSON 파일에서 ConsoleLogin 이벤트만 찾아 시간·사용자·IP·성공/실패를 보여주고 CSV로 저장합니다. MFA 없는 로그인·IP 변화·실패 횟수에 대한 별도 경고는 만들지 않습니다.

JSON 파일 → 이벤트 목록 → ConsoleLogin 선택 → 4개 열의 표 → CSV

실행

Rscript -e 'install.packages("jsonlite")'
Rscript login_records.R 로그.json
Rscript login_records.R 로그.json 결과.csv

파일 다운로드는 하지 않습니다. AWS 계정의 콘솔 로그인 CloudTrail 이벤트가 포함된 파일을 입력하세요. AWS CLI나 SDK를 호출하지 않습니다.

① 파일 읽기

readLines()로 줄별 문자열을 읽고 빈 줄을 제거합니다. 먼저 파일 전체를 JSON으로 해석합니다. 실패하면 줄마다 JSON인 NDJSON으로 읽습니다. 손상된 입력은 오류를 내며 중간 파일을 정상 결과로 저장하지 않습니다.

login_records.R · 20–39행
20read_events <- function(path) {21  lines <- readLines(path, warn = FALSE, encoding = "UTF-8")22  lines <- lines[nzchar(trimws(lines))]23  if (!length(lines)) return(list())24  # 우선 파일 전체를 JSON으로 읽고, 실패하면 NDJSON으로 읽습니다.25  parsed <- tryCatch(26    jsonlite::fromJSON(paste(lines, collapse = "\n"), simplifyVector = FALSE),27    error = function(e) NULL28  )29  if (!is.null(parsed)) return(event_list(parsed))30  result <- list()31  for (i in seq_along(lines)) {32    item <- tryCatch(33      jsonlite::fromJSON(lines[[i]], simplifyVector = FALSE),34      error = function(e) stop(sprintf("JSON 파싱 실패: 비어 있지 않은 %d번째 줄", i))35    )36    result <- c(result, event_list(item))37  }38  result39}

② 이벤트 목록으로 맞추기

Records 포장이 있으면 내부 배열을 꺼냅니다. 단일 이벤트이면 list(x)로 감싸고, 이벤트 배열은 그대로 사용합니다. 서로 다른 입력 형식을 같은 함수에 전달하기 위한 과정입니다.

③ ConsoleLogin만 선택

Filter()의 조건은 이벤트가 리스트이고 eventName이 정확히 ConsoleLogin인지입니다. 일반 API 호출은 제외하며 성공·실패 모두 포함합니다. 반복 실패·IP 변경·MFA 여부는 판정하지 않습니다.

login_records.R · 41–62행
41login_records <- function(events) {42  # ConsoleLogin만 남깁니다. 로그인 실패와 성공을 모두 포함합니다.43  selected <- Filter(function(e) is.list(e) &&44    identical(e$eventName, "ConsoleLogin"), events)45  rows <- lapply(selected, function(e) {46    user <- text_value(e$userIdentity$userName)47    if (is.na(user)) user <- text_value(e$userIdentity$arn)48    data.frame(49      time = text_value(e$eventTime),50      user = user,51      ip = text_value(e$sourceIPAddress),52      result = text_value(e$responseElements$ConsoleLogin),53      stringsAsFactors = FALSE54    )55  })56  if (!length(rows)) return(data.frame(57    time = character(), user = character(), ip = character(), result = character()58  ))59  output <- do.call(rbind, rows)60  # CloudTrail UTC ISO 형식의 원본 시각 문자열을 오름차순으로 정렬합니다.61  output[order(output$time, na.last = TRUE), , drop = FALSE]62}

④ 4개 열 만들기

시간·사용자·IP·결과를 data.frame() 한 행으로 만듭니다. 사용자는 userName이 없으면 ARN을 사용합니다. text_value()는 누락 필드를 NA로 통일합니다. 실제 값이 있어도 첫 원소만 사용합니다.

login_records.R · 8–10행
8text_value <- function(x) {9  if (is.null(x) || length(x) == 0) NA_character_ else as.character(x[[1]])10}

lapply()의 행 목록을 do.call(rbind, rows)로 합칩니다. 결과가 0건이어도 같은 열을 가진 빈 표를 반환합니다. UTC ISO 시각 문자열을 오름차순으로 정렬합니다.

⑤ 화면 출력과 CSV 저장

commandArgs()로 입력·출력 경로를 받습니다. 출력 경로를 생략하면 output/login_records.csv를 사용합니다. write.csv()가 행 번호 없이 UTF-8로 저장하고 누락값은 빈칸으로 표시합니다. print()는 표를 화면에 출력합니다.

64if (sys.nframe() == 0) {65  args <- commandArgs(trailingOnly = TRUE)66  if (!length(args)) stop("사용법: Rscript login_records.R 로그.json [출력.csv]")67  destination <- if (length(args) >= 2) args[[2]] else "output/login_records.csv"68  records <- login_records(read_events(args[[1]]))69  dir.create(dirname(destination), recursive = TRUE, showWarnings = FALSE)70  write.csv(records, destination, row.names = FALSE, na = "", fileEncoding = "UTF-8")71  print(records, row.names = FALSE)72  cat(sprintf("로그인 기록 %d건 저장: %s\n", nrow(records), destination))73}

검증과 범위

가상 데이터로 실제 R 실행과 CSV 저장을 확인했습니다. Records·배열·단일 이벤트·NDJSON·빈 파일·로그인 없는 파일·잘못된 JSON을 검사했고, 성공/실패 유지·시간 정렬·ARN 대체·누락값도 확인했습니다.

이 프로그램은 ConsoleLogin 기록 추출기입니다. 실제 공격 판정이나 탐지 성능 평가는 수행하지 않습니다. 파일 전체를 메모리에 읽으므로 대용량 스트리밍 도구가 아닙니다. 동일 이벤트 중복 제거는 하지 않습니다.
