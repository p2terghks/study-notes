위 예시는 코드 이해를 위한 가상 데이터입니다. event_time >= t & event_time <= t + window_min * 60는 각 실패가 구간 안에 있는지 논리값을 만듭니다. sum()은 TRUE를 1로 세고, vapply(..., numeric(1))는 각 시작점에서 숫자 하나씩 반환하도록 요구합니다. max()로 최댓값 3을 선택합니다.

전체 실패 n_total은 4이지만 집중 구간의 최대 실패 n은 3입니다. 기본 임계값 3을 만족하므로 medium 탐지 한 건이 생성됩니다. 최대 5회 이상이면 high입니다.

해석 주의

결과의 event_time은 집중 구간 시작점이 아니라 그룹 전체 최초 실패 시각입니다. source_ip도 전체 그룹의 IP입니다. 여러 집중 구간이 있어도 그룹당 한 행으로 요약합니다. NA 시각을 별도로 처리하지 않고, 매 시각마다 전체를 비교하므로 그룹 크기가 커지면 대략 제곱 수준의 비교 비용이 발생합니다.
