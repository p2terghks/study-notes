전체 19개 함수 관계도

main이 화면을 만든 뒤 사진 선택과 비교 버튼을 누르는 순서입니다. poll은 OCR 작업 큐를 주기적으로 확인합니다. 반복해서 사용하는 함수는 여러 가지에 표시했습니다.

전체 호출 관계

app.main()
├─ choice() → 입학년도·전공 선택 상자
├─ 사진 선택 버튼 → load()
│  └─ worker() [별도 스레드]
│     ├─ ocr.recognize(사진 bytes)
│     │  ├─ recognize_grid_table(pixels)
│     │  │  ├─ grid_boundaries(pixels)
│     │  │  │  └─ positions(True / False)
│     │  │  ├─ get_reader()
│     │  │  ├─ cell(열, 제목 행) → header_field(제목)
│     │  │  └─ cell(과목명 열, 각 행)
│     │  └─ 표 인식 실패 → get_reader().readtext()
│     ├─ 행마다 app.review_row(line, 전공)
│     │  ├─ matcher.match(name, track) [complete_name 별칭]
│     │  │  ├─ names(track) → rules.catalog(track) → key(이름)
│     │  │  ├─ rules.key(name)
│     │  │  └─ 자모 유사도 비교 → 표준명 또는 원문
│     │  ├─ rules.key(name) → CREDITS 학점 조회
│     │  └─ rules.catalog(track) → 영역 조회
│     └─ events.put() → 큐에 검토 문자열 리스트 저장
├─ poll() [150ms 간격으로 다음 호출 예약]
│  └─ 큐의 결과 → 검토표 표시
└─ 비교 버튼 → calculate()
   ├─ matcher.match() / rules.key() / rules.catalog()
   └─ rules.report(rows, track)
      ├─ rules.catalog(track) / rules.key(이름)
      └─ 중복 제거 → 합산 → 부족 학점·이수 후보 → 결과창
