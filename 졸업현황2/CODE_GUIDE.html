화면과 코드가 연결되는 순서

  • 브라우저가 /를 요청하면 index()가 HTML을 반환합니다. CSS와 JavaScript를 따로 불러옵니다.
  • JavaScript가 GET /api/config를 호출하여 12개 교육과정과 이수구분 목록을 받습니다.
  • 사진은 POST /api/ocr, 텍스트는 /api/parse, CSV는 /api/csv로 전송합니다.
  • 서버는 과목 후보 rows, 미해석 행 rejected, 원문 raw, 검토 토큰 review_token을 JSON으로 반환합니다.
  • setRows()가 브라우저 상태를 바꾸고 renderRows()가 편집 표를 만듭니다.
  • 사용자가 표를 수정하면 해당 행의 확인을 해제하고 이전 결과를 숨깁니다.

자료형은 왜, 어디서 바뀌나요?

사진: File → FormData → bytes

const form = new FormData();
form.append('profile', profile.id);
files.forEach(f => form.append('photos', f));
setRows(await api('/api/ocr', form));

브라우저의 File은 사용자가 선택한 파일을 나타냅니다. FormData는 사진과 교육과정 ID를 HTTP 요청에 함께 넣기 위한 전송 형식입니다. JavaScript가 사진을 딕셔너리로 형변환하는 것이 아닙니다. api()는 FormData일 때 Content-Type을 직접 지정하지 않고 브라우저가 multipart 경계값을 포함해 정하도록 둡니다.

photos = request.files.getlist('photos')
content = photo.read(15 * 1024 * 1024 + 1)
lines, _ = recognize(content)

서버의 업로드 파일 객체에서 read()로 bytes를 읽습니다. JPEG/PNG는 이미 파일 바이트로 인코딩되어 있으므로 bytes(photo)로 새로 형변환하지 않습니다. 최대 허용량보다 1바이트 더 읽어 초과를 검사합니다. 업로드는 크기 제한 아래 메모리에서 처리합니다.

bytes → 이미지 객체 → NumPy 배열

source = Image.open(io.BytesIO(image_bytes))
image = ImageOps.exif_transpose(source).convert('RGB')
image.thumbnail((2600, 2600))
detections = get_reader().readtext(np.array(image), detail=1, paragraph=False)

BytesIO는 bytes를 파일처럼 읽을 수 있게 감쌉니다. Image.open은 파일 형식을 해석하고, 실제 코드에서는 화소 수를 먼저 검사한 뒤 방향·색상을 정리합니다. np.array(image)는 픽셀을 (높이, 너비, 3) 형태의 RGB 숫자 배열로 만듭니다. 이후 EasyOCR 내부에서 모델용 전처리·텐서 변환이 이뤄집니다. 이 프로젝트가 직접 torch.tensor()를 호출하지는 않습니다.

OCR 결과 → 딕셔너리 목록

boxes.append({'x': float(min(xs)), 'y': float(sum(ys) / 4),
              'height': float(max(ys) - min(ys)),
              'text': text, 'confidence': float(confidence)})

한 문자 영역은 위치·문자·신뢰도를 가진 딕셔너리입니다. boxes는 여러 영역을 담은 리스트입니다. append({...})는 딕셔너리 하나를 만들어 리스트 끝에 붙이는 코드입니다. 이후 위치별로 묶고 문자열을 이어 붙여 lines를 만듭니다.

문자열 학점 → float / 과목 정보 → rows

name, credits, grade = match.groups()

정규표현식의 추출값은 문자열입니다. 후보 딕셔너리를 만들 때 float(credits)로 '3'을 3.0으로 바꿔 합산할 수 있게 합니다. rows.append({...})로 한 과목을 리스트에 추가합니다. 정확히 일치하는 과목만 자동 분류하며, 확인은 False로 시작합니다. 해석에 실패한 줄은 원문과 이유를 rejected에 남깁니다.

Python 자료구조 → JSON → JavaScript 객체

jsonify()는 Python 딕셔너리·리스트를 JSON HTTP 응답으로 직렬화합니다. 브라우저의 await response.json()은 JSON을 JavaScript 객체·배열로 해석합니다. Python dict와 JavaScript object는 같은 메모리 객체가 아니며, 네트워크에서 JSON을 통해 정보를 주고받습니다.

JavaScript 객체 배열 → HTML 표

rows.forEach()로 과목을 순회하고 document.createElement()로 tr·td·input·select를 만듭니다. 화면 텍스트는 textContent, 편집값은 input.value로 넣습니다. 입력 이벤트에서 row[key] = input.value로 메모리 데이터를 바꿉니다. HTML 표 자체를 서버로 보내는 것이 아니라 이 객체 배열을 JSON으로 보냅니다. 숫자 입력칸의 value도 문자열일 수 있어 서버 계산 단계에서 다시 숫자로 검사합니다. 새 버전은 pandas DataFrame을 사용하지 않습니다.

점검 요청 → 결과 → 다운로드

JSON.stringify()로 요청 객체를 문자열로 직렬화하고 Flask의 request.get_json()으로 다시 읽습니다. 서버는 확인·학점·성적·교육과정·중복을 검사하고 인정 가능한 행만 합산합니다. 결과를 다운로드할 때는 JSON.stringify(result, null, 2)와 new Blob()을 사용합니다. 이는 브라우저 다운로드를 준비하는 코드이며 서버 디스크에 성적표를 저장하지 않습니다.

상태와 검토 토큰

  • invalidate(): epoch를 1 올리고 결과를 숨깁니다. 입력이나 기준을 바꿨을 때 이전 결과를 무효화합니다.
  • epoch: 요청을 보낸 시점의 값과 응답 시점의 값이 다르면 늦게 도착한 결과를 버립니다.
  • busy / task(): 중복 요청을 줄이고 실패 메시지를 표시한 뒤 버튼 상태를 복구합니다.
  • review_token: 서버가 교육과정 ID와 미해석 행 개수에 서명한 값입니다. 위조 여부·기준 일치 여부를 확인하고, 미해석 행이 있었다면 추가 확인을 요구합니다.
  • 토큰은 성적표 진위나 사용자가 실제로 원문을 읽었다는 증거가 아닙니다. 사진 내용의 암호화도 아닙니다. 서버를 재시작하면 기존 토큰은 무효가 되어 입력을 다시 불러와야 합니다.
  • rows 등은 브라우저 메모리에 있으며 새로고침하면 사라집니다. localStorage에는 다크모드 선택만 저장합니다.

app.py · parse_csv()

CSV 바이트를 UTF-8 문자열로 디코딩하고 StringIO·DictReader로 행 딕셔너리 목록을 만듭니다. 파일에 확인=True가 있어도 False로 초기화합니다.

현재 소스 93–115행
@app.post('/api/csv')
def parse_csv():
    profile = profile_for(request.form.get('profile'))
    upload = request.files.get('file')
    if not upload:
        raise ValueError('CSV 파일을 선택하세요.')
    content = upload.read(2 * 1024 * 1024 + 1)
    if len(content) > 2 * 1024 * 1024:
        raise ValueError('CSV는 2MB 이하로 올려주세요.')
    try:
        reader = csv.DictReader(io.StringIO(content.decode('utf-8-sig')))
        if not {'과목명', '학점', '이수구분', '성적'}.issubset(reader.fieldnames or []):
            raise ValueError('과목명·학점·이수구분·성적 열이 필요합니다.')
        rows = []
        for record in reader:
            if len(rows) >= 500:
                raise ValueError('CSV는 500행 이하로 올려주세요.')
            row = {key: (record.get(key) or '') for key in ['과목명', '학점', '이수구분', '성적']}
            row.update({'확인': False, '인식신뢰도': 1.0, '메모': 'CSV 입력'})
            rows.append(row)
    except UnicodeError:
        raise ValueError('UTF-8 형식으로 저장한 CSV를 사용하세요.') from None
    return candidates_response(profile, rows, [])
app.py · ocr()

업로드 수·크기·이미지 형식을 검사한 뒤 실제 recognize를 호출합니다. 여러 사진의 행을 extend로 합칩니다. 동시 OCR 요청은 잠금으로 제한하고 finally에서 해제합니다.

현재 소스 118–147행
@app.post('/api/ocr')
def ocr():
    profile = profile_for(request.form.get('profile'))
    photos = request.files.getlist('photos')
    if not 1 <= len(photos) <= 5:
        raise ValueError('사진은 한 번에 1~5장 선택하세요.')
    if not ocr_lock.acquire(blocking=False):
        return jsonify(error='다른 사진을 인식 중입니다. 잠시 후 다시 시도하세요.'), 409
    try:
        rows, rejected, raw = [], [], []
        for photo in photos:
            content = photo.read(15 * 1024 * 1024 + 1)
            if len(content) > 15 * 1024 * 1024:
                raise ValueError('사진 한 장은 15MB 이하로 올려주세요.')
            from PIL import Image, UnidentifiedImageError
            try:
                image = Image.open(io.BytesIO(content))
                if image.format not in {'JPEG', 'PNG', 'WEBP'}:
                    raise ValueError('JPG·PNG·WEBP 사진만 사용할 수 있습니다.')
                image.close()
                lines, _ = recognize(content)
            except (UnidentifiedImageError, OSError):
                raise ValueError('사진을 읽을 수 없습니다. 파일을 확인하세요.') from None
            candidates, failures = parse_lines_with_review(lines, profile)
            rows.extend(candidates)
            rejected.extend(failures)
            raw.extend(lines)
        return candidates_response(profile, rows, rejected, raw)
    finally:
        ocr_lock.release()
app.py · check()

검토 토큰·교육과정·동의·행 형식·의무 과목·심화 옵션을 검사한 뒤 audit를 호출합니다. 토큰이 성적표 진위를 보장하지는 않습니다.

현재 소스 150–184행
@app.post('/api/audit')
def check():
    body = request.get_json()
    if not isinstance(body, dict):
        raise ValueError('잘못된 입력 형식입니다.')
    profile = profile_for(body.get('profile'))
    try:
        token = signer.loads(body.get('review_token', ''))
    except (BadSignature, TypeError):
        raise ValueError('입력을 다시 불러온 뒤 검토하세요.') from None
    if token.get('profile') != profile['id']:
        raise ValueError('교육과정이 바뀌었습니다. 입력을 다시 불러오세요.')

def recognize(image_bytes):
    import io
    import numpy as np
    from PIL import Image, ImageOps
    source = Image.open(io.BytesIO(image_bytes))
    if source.width*source.height>24_000_000:
        raise ValueError('이미지는 2,400만 화소 이하로 줄여주세요.')
    image=ImageOps.exif_transpose(source).convert('RGB')
    image.thumbnail((2600,2600))

    boxes=[]
    for box,text,confidence in detections:
        xs=[p[0] for p in box]; ys=[p[1] for p in box]
        boxes.append({'x':float(min(xs)),'y':float(sum(ys)/4),'height':float(max(ys)-min(ys)),
                      'text':text,'confidence':float(confidence)})
    groups=[]
    for item in sorted(boxes,key=lambda b:b['y']):
        target=next((g for g in groups if abs(g[0]['y']-item['y'])<=max(7,min(g[0]['height'],item['height'])*.5)),None)
        if target is None: groups.append([item])
        else: target.append(item)
    lines=[{'text':' '.join(b['text'] for b in sorted(g,key=lambda b:b['x'])),
            'confidence':min(b['confidence'] for b in g)} for g in groups]
    return lines,boxes

def parse_lines_with_review(lines, profile):
    """Return candidates and every nonempty unparsed line for manual review."""
    rows, rejected = [], []
    grades = sorted(PASS_GRADES | FAIL_GRADES, key=len, reverse=True)
    grade_pattern = "(?:" + "|".join(re.escape(g) for g in grades) + ")"
    pattern = re.compile(
        rf"^\s*(.+?)\s+(\d+(?:\.\d+)?)\s*(?:학점\s*)?"
        rf"({grade_pattern})(?:\s+(?:[0-4](?:\.\d+)?|5(?:\.0+)?))?\s*$", re.I)
    for line in lines:
        text = line['text'] if isinstance(line, dict) else line
        confidence = line.get('confidence', 1.0) if isinstance(line, dict) else 1.0
        text = text.strip()
        if not text:
            continue
        if re.match(r'^(총학점|합계|취득학점|평균|신청학점)(?:\s|$)', text):
            continue
        match = pattern.fullmatch(text)
        if match:
            name, credits, grade = match.groups()
            # A prior grade/credit pair indicates merged columns or two courses.
            if re.search(rf"\s\d+(?:\.\d+)?\s+{grade_pattern}(?=\s|$)", name, re.I):
                rejected.append({'text': text, 'reason': '한 줄에 여러 과목이 있어 분리해야 합니다.'})
                continue
        else:
            missing_grade = re.fullmatch(r'(.+?)\s+(\d+(?:\.\d+)?)\s*', text)
            if not missing_grade or not suggest(missing_grade[1], profile)[1]:
                rejected.append({'text': text, 'reason': '과목명·학점·성적 열을 확인하세요.'})
                continue
            name, credits = missing_grade.groups()
            grade = ''
        course, exact = suggest(name, profile)
        rows.append({'과목명': course['name'] if exact else name, '학점': float(credits),
                     '이수구분': course['category'] if exact else '미분류', '성적': grade.upper(),
                     '확인': False, '인식신뢰도': round(float(confidence), 3),
                     '메모': '' if exact else f'과목 후보: {course["name"]}' if course else '교육과정 목록에 없음'})
    return rows, rejected

@app.post('/api/csv')
def parse_csv():
    profile = profile_for(request.form.get('profile'))
    upload = request.files.get('file')
    if not upload:
        raise ValueError('CSV 파일을 선택하세요.')
    content = upload.read(2 * 1024 * 1024 + 1)
    if len(content) > 2 * 1024 * 1024:
        raise ValueError('CSV는 2MB 이하로 올려주세요.')
    try:
        reader = csv.DictReader(io.StringIO(content.decode('utf-8-sig')))
        if not {'과목명', '학점', '이수구분', '성적'}.issubset(reader.fieldnames or []):
            raise ValueError('과목명·학점·이수구분·성적 열이 필요합니다.')
        rows = []
        for record in reader:
            if len(rows) >= 500:
                raise ValueError('CSV는 500행 이하로 올려주세요.')
            row = {key: (record.get(key) or '') for key in ['과목명', '학점', '이수구분', '성적']}
            row.update({'확인': False, '인식신뢰도': 1.0, '메모': 'CSV 입력'})
            rows.append(row)
    except UnicodeError:
        raise ValueError('UTF-8 형식으로 저장한 CSV를 사용하세요.') from None
    return candidates_response(profile, rows, [])


@app.post('/api/ocr')
def ocr():
    profile = profile_for(request.form.get('profile'))
    photos = request.files.getlist('photos')
    if not 1 <= len(photos) <= 5:
        raise ValueError('사진은 한 번에 1~5장 선택하세요.')
    if not ocr_lock.acquire(blocking=False):
        return jsonify(error='다른 사진을 인식 중입니다. 잠시 후 다시 시도하세요.'), 409
    try:
        rows, rejected, raw = [], [], []
        for photo in photos:
            content = photo.read(15 * 1024 * 1024 + 1)
            if len(content) > 15 * 1024 * 1024:
                raise ValueError('사진 한 장은 15MB 이하로 올려주세요.')
            from PIL import Image, UnidentifiedImageError
            try:
                image = Image.open(io.BytesIO(content))
                if image.format not in {'JPEG', 'PNG', 'WEBP'}:
                    raise ValueError('JPG·PNG·WEBP 사진만 사용할 수 있습니다.')
                image.close()
                lines, _ = recognize(content)
            except (UnidentifiedImageError, OSError):
                raise ValueError('사진을 읽을 수 없습니다. 파일을 확인하세요.') from None
            candidates, failures = parse_lines_with_review(lines, profile)
            rows.extend(candidates)
            rejected.extend(failures)
            raw.extend(lines)
        return candidates_response(profile, rows, rejected, raw)
    finally:
        ocr_lock.release()


@app.post('/api/audit')
def check():
    body = request.get_json()
    if not isinstance(body, dict):
        raise ValueError('잘못된 입력 형식입니다.')
    profile = profile_for(body.get('profile'))
    try:
        token = signer.loads(body.get('review_token', ''))
    except (BadSignature, TypeError):
        raise ValueError('입력을 다시 불러온 뒤 검토하세요.') from None
    if token.get('profile') != profile['id']:
        raise ValueError('교육과정이 바뀌었습니다. 입력을 다시 불러오세요.')
    if body.get('consent') is not True or (token['rejected'] and body.get('resolved') is not True):
        raise ValueError('원문 및 미해석 행 검토를 완료하세요.')
    rows = body.get('rows')
    if not isinstance(rows, list) or not 1 <= len(rows) <= 500:
        raise ValueError('검토할 과목을 1~500개 입력하세요.')
    for row in rows:
        if not isinstance(row, dict):
            raise ValueError('과목 정보 형식이 올바르지 않습니다.')
        for key in ['과목명', '이수구분', '성적']:
            if not isinstance(row.get(key), str) or len(row[key]) > 300:
                raise ValueError('과목명·구분·성적은 300자 이내 문자열로 입력하세요.')
        if not isinstance(row.get('학점'), (str, int, float)) or isinstance(row.get('학점'), bool):
            raise ValueError('학점은 숫자로 입력하세요.')
    if not any(row['과목명'].strip() for row in rows):
        raise ValueError('과목명을 입력하세요.')
    mandatory = body.get('mandatory', [])
    allowed = {c['name'] for c in profile['courses'] if c['category'] == '전공필수'}
    if not isinstance(mandatory, list) or any(not isinstance(x, str) or x not in allowed for x in mandatory):
        raise ValueError('의무 과목 선택을 확인하세요.')
    advanced = body.get('advanced', False)
    if not isinstance(advanced, bool) or (advanced and profile['optional_advanced'] is None):
        raise ValueError('이 교육과정에서는 전공심화 추가 검사를 선택할 수 없습니다.')
    return jsonify(audit(rows, profile, mandatory, advanced))

"""Deterministic credit audit; OCR never decides graduation eligibility."""
import math
import re
import unicodedata
from difflib import get_close_matches

CATEGORIES = ['전공필수','전공선택','전공심화','기초교양','나사렛교양','핵심교양','소양교양','자율선택','미분류']
PASS_GRADES = {'A+','A0','A','A-','B+','B0','B','B-','C+','C0','C','C-','D+','D0','D','D-','P','PASS','S','이수','이수완료'}
FAIL_GRADES = {'F','NP','N','U','FAIL','W','철회','미이수','수강중'}

def normalize(value):
    return re.sub(r'\s+','',unicodedata.normalize('NFKC',str(value or ''))).casefold()

def catalog_index(profile):
    return {normalize(c['name']):c for c in profile['courses']}

def suggest(name, profile):
    catalog=catalog_index(profile); key=normalize(name)
    if key in catalog: return catalog[key], True
    near=get_close_matches(key,list(catalog),n=1,cutoff=.65)
    return (catalog[near[0]],False) if near else (None,False)

def parse_lines_with_review(lines, profile):
    """Return candidates and every nonempty unparsed line for manual review."""
    rows, rejected = [], []
    grades = sorted(PASS_GRADES | FAIL_GRADES, key=len, reverse=True)
    grade_pattern = "(?:" + "|".join(re.escape(g) for g in grades) + ")"
    pattern = re.compile(
        rf"^\s*(.+?)\s+(\d+(?:\.\d+)?)\s*(?:학점\s*)?"
        rf"({grade_pattern})(?:\s+(?:[0-4](?:\.\d+)?|5(?:\.0+)?))?\s*$", re.I)
    for line in lines:
        text = line['text'] if isinstance(line, dict) else line
        confidence = line.get('confidence', 1.0) if isinstance(line, dict) else 1.0
        text = text.strip()
        if not text:
            continue
        if re.match(r'^(총학점|합계|취득학점|평균|신청학점)(?:\s|$)', text):
            continue
        match = pattern.fullmatch(text)
        if match:
            name, credits, grade = match.groups()
            # A prior grade/credit pair indicates merged columns or two courses.
            if re.search(rf"\s\d+(?:\.\d+)?\s+{grade_pattern}(?=\s|$)", name, re.I):
                rejected.append({'text': text, 'reason': '한 줄에 여러 과목이 있어 분리해야 합니다.'})
                continue
        else:
            missing_grade = re.fullmatch(r'(.+?)\s+(\d+(?:\.\d+)?)\s*', text)
            if not missing_grade or not suggest(missing_grade[1], profile)[1]:
                rejected.append({'text': text, 'reason': '과목명·학점·성적 열을 확인하세요.'})
                continue
            name, credits = missing_grade.groups()
            grade = ''
        course, exact = suggest(name, profile)
        rows.append({'과목명': course['name'] if exact else name, '학점': float(credits),
                     '이수구분': course['category'] if exact else '미분류', '성적': grade.upper(),
                     '확인': False, '인식신뢰도': round(float(confidence), 3),
                     '메모': '' if exact else f'과목 후보: {course["name"]}' if course else '교육과정 목록에 없음'})
    return rows, rejected


def parse_lines(lines, profile):
    """Compatibility helper; interactive imports use parse_lines_with_review."""
    return parse_lines_with_review(lines, profile)[0]

def audit(rows, profile, mandatory=(), advanced=False):
    catalog=catalog_index(profile)
    totals={c:0.0 for c in CATEGORIES}
    accepted={}; issues=[]; excluded=[]
    for i,row in enumerate(rows,1):
        name=str(row.get('과목명','') or '').strip()
        if not name: continue
        if row.get('확인') is not True:
            issues.append(f'{i}행 {name}: 원문 확인이 필요합니다.'); continue
        category=row.get('이수구분','미분류')
        if category not in CATEGORIES or category=='미분류':
            issues.append(f'{i}행 {name}: 이수구분을 지정하세요.'); continue
        try: credits=float(row.get('학점'))
        except (ValueError,TypeError): credits=float('nan')
        if not math.isfinite(credits) or credits<=0 or credits>30:
            issues.append(f'{i}행 {name}: 유효한 학점(0 초과 30 이하)을 입력하세요.'); continue
        grade=str(row.get('성적','')).strip().upper()
        if grade in FAIL_GRADES:
            excluded.append(f'{name}: {grade} (취득학점 제외)'); continue
        if grade not in PASS_GRADES:
            issues.append(f'{i}행 {name}: 성적을 확인하세요.'); continue
        key=normalize(name)
        course = catalog.get(key)
        if course and (credits != float(course['credits']) or category != course['category']):
            issues.append(f'{i}행 {name}: 교육과정은 {course["category"]} {course["credits"]}학점입니다. 입력을 수정하거나 학과에서 인정 기준을 확인하세요.')
            continue
        if not course and category.startswith('전공'):
            issues.append(f'{i}행 {name}: 교육과정에 없는 전공 과목입니다. 과목명·대체 인정 여부를 확인하세요.')
            continue
        # Conflicting repeated records require a user decision, never a silent sum.
        if key in accepted:
            old=accepted[key]
            if old['학점']!=credits or old['이수구분']!=category:
                issues.append(f'{name}: 중복 내역의 학점 또는 구분이 다릅니다. 한 행만 남기세요.')
            else: excluded.append(f'{name}: 중복 취득은 1회만 계산')
            continue
        accepted[key]={'과목명':name,'학점':credits,'이수구분':category,'성적':grade}
        totals[category]+=credits
    totals['총학점']=sum(totals.values())
    totals['교양합계']=sum(totals[c] for c in ['기초교양','나사렛교양','핵심교양','소양교양'])
    totals['전공합계']=sum(totals[c] for c in ['전공필수','전공선택','전공심화'])
    # Advanced courses contribute to elective minima; no double counting in total.
    totals['전공선택']+=totals['전공심화']
    checks=[{'항목':key,'필요학점':value,'인정학점':totals[key],
             '부족학점':max(0,value-totals[key])} for key,value in profile['minimums'].items()]
    if advanced:
        if profile['optional_advanced'] is None:
            issues.append('이 연도의 전공심화 최소학점이 제공되지 않아 확인이 필요합니다.')
        else:
            value=profile['optional_advanced']
            checks.append({'항목':'선택한 전공심화','필요학점':value,'인정학점':totals['전공심화'],
                           '부족학점':max(0,value-totals['전공심화'])})
    missing=[name for name in mandatory if normalize(name) not in accepted]
    uncompleted=[c for key,c in catalog.items() if c['category']=='전공필수' and key not in accepted]
    status='입력 검토 필요' if issues else '입력 기준 미충족' if missing or any(c['부족학점'] for c in checks) else '입력한 학점·지정 과목 기준 충족 (공식 요건 확인 대기)'

def recognize(image_bytes):
    import io
    import numpy as np
    from PIL import Image, ImageOps
    source = Image.open(io.BytesIO(image_bytes))
    if source.width*source.height>24_000_000:
        raise ValueError('이미지는 2,400만 화소 이하로 줄여주세요.')
    image=ImageOps.exif_transpose(source).convert('RGB')
    image.thumbnail((2600,2600))
    detections=get_reader().readtext(np.array(image),detail=1,paragraph=False)
    boxes=[]
    for box,text,confidence in detections:
        xs=[p[0] for p in box]; ys=[p[1] for p in box]
        boxes.append({'x':float(min(xs)),'y':float(sum(ys)/4),'height':float(max(ys)-min(ys)),
                      'text':text,'confidence':float(confidence)})
    groups=[]
    for item in sorted(boxes,key=lambda b:b['y']):
        target=next((g for g in groups if abs(g[0]['y']-item['y'])<=max(7,min(g[0]['height'],item['height'])*.5)),None)
        if target is None: groups.append([item])
        else: target.append(item)
    lines=[{'text':' '.join(b['text'] for b in sorted(g,key=lambda b:b['x'])),
            'confidence':min(b['confidence'] for b in g)} for g in groups]
    return lines,boxes

"""Real model smoke test using a synthetic transcript without student data."""
import json
import sys
from pathlib import Path
ROOT=Path(__file__).resolve().parents[1]
sys.path.insert(0,str(ROOT))
from graduation.ocr import recognize
from graduation.engine import parse_lines, parse_lines_with_review, audit

if __name__=='__main__':
    data=json.loads((ROOT/'data/curriculum.json').read_text())
    profile=next(p for p in data['profiles'] if p['id']=='2025-인공지능빅데이터')
    lines,_=recognize((ROOT/'data/sample-transcript.png').read_bytes())
    rows,rejected=parse_lines_with_review(lines,profile)
    print(json.dumps({'lines':lines,'rows':rows,'rejected':rejected},ensure_ascii=False,indent=2))
    expected={'컴퓨터프로그래밍1','JAVA','DB이론및실습','자료구조'}
    assert len(rows)+len(rejected)==4, '샘플의 4개 행이 후보 또는 검토 목록에 모두 남아야 합니다.'
    exact=sum(r['과목명'] in expected for r in rows)
    print(f'구조화한 후보 중 정확한 과목명: {exact}/4. 나머지 후보는 사용자 검토가 필요합니다.')
    corrected=parse_lines(['컴퓨터프로그래밍1 3 A+','JAVA 3 B0','DB이론및실습 3 P','자료구조 3 F'],profile)
    for row in corrected: row['확인']=True
    result=audit(corrected,profile)
    assert result['total']==9 and not result['issues'], '사용자 수정 후 학점 계산 오류'
    assert all(not r['확인'] for r in rows), '인식 결과는 사용자 확인을 요구해야 합니다.'
    print('실제 OCR 4행의 후보·미해석 보존 및 사용자 수정 후 9학점 계산 검증 완료')
