# 졸업 체크 AI — 수정 요약

사진 속 성적표를 PyTorch 기반 EasyOCR로 읽고, 사용자가 검토한 이수 내역을 교육과정과 대조하는 졸업 사전 점검 시스템입니다. 공식 졸업 판정을 자동 확정하지 않습니다.

## 2026-10-29 수정

- 교육과정에 있는 과목은 학점·이수구분이 일치해야 합산합니다. 예를 들어 JAVA를 기초교양 30학점으로 입력하면 제외하고 수정 사유를 표시합니다.
- 교육과정에 없는 전공 과목은 대체 인정 여부를 확인하기 전까지 합산하지 않습니다. 공식 예외 처리 기능은 아직 없으므로 정당한 대체 과목도 학과 확인이 필요합니다.
- `parse_lines_with_review(lines, profile)`는 `(과목 후보, 미해석 행)`을 반환합니다. `parse_lines`는 기존 호출을 위한 호환 함수입니다.
- `이수완료` 성적을 인식하고, `JAVA 3 A+ 4.5`에서 학점 3과 뒤의 평점 4.5를 구분합니다.
- 두 과목이 합쳐진 행과 알 수 없는 성적은 무리하게 인정하지 않고 검토 목록으로 보냅니다. 미해석 행의 원문과 사유를 표시하며, 사용자가 필요한 과목을 추가했다고 확인해야 점검할 수 있습니다.
- 새 입력과 교육과정 변경 시 미해석 행·OCR 원문 상태를 초기화합니다.
- 조건을 채운 경우에도 ‘공식 요건 확인 대기’를 표시합니다. 총학점 화면은 고정 숫자 대신 선택한 교육과정의 최소학점을 사용합니다.
- 이미지 방향·색상 변환 전에 화소 제한을 검사합니다.
- 기본 가이드·상세 가이드·클릭형 다이어그램의 소스 발췌와 설명을 갱신했습니다.

## 검사 결과

`python -m unittest discover -s tests -v`: 21개 통과. 기존 13개에 입력 불일치, 미등록 전공, 한글 성적, 평점 열, 합쳐진 행, 미해석 행의 화면 확인 절차 등을 검증하는 8개를 추가했습니다.

## 아직 남은 한계

1. 실제 성적표 사진의 인식률은 측정하지 않았습니다. 기존 가상 사진 4과목 중 이름 2개를 정확히 인식한 기록은 전체 정확도로 일반화할 수 없습니다. 인식 오류가 모두 해결되었다는 뜻이 아닙니다.
2. 복잡한 다단 표는 OCR에서 잘못 합쳐질 수 있습니다. 이번 변경은 탐지 가능한 잘못된 행을 검토 대상으로 보내지만 모든 형태를 자동 분리하지는 않습니다. 미해석 행에는 제목 등 과목이 아닌 행도 포함될 수 있습니다.
3. 공식 과목코드·수강학기·대체과목 대응표가 없어 이름이 바뀐 과목 및 재수강 인정은 완전하게 처리하지 못합니다. 이름이 같은 과목은 기존처럼 한 번만 합산합니다.
4. 교양 과목 목록이 완비되어 있지 않아 교양의 이름·학점·구분은 사용자 검토에 의존합니다.
5. 졸업시험·논문·인증·교양 의무 과목·복수전공 등은 자동 판정하지 않습니다. 전공심화를 전공선택에 포함하는 기존 계산 가정도 학과 확인이 필요합니다.
