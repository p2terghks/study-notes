# 졸업 체크 AI

성적표 사진을 PyTorch 기반 EasyOCR로 읽고, 사용자가 검토한 이수 내역을 나사렛대학교 첨부 교육과정표와 비교하는 독립 로컬 앱입니다. 기존 graduation-ai 및 다른 프로젝트를 변경하지 않습니다.

## 최신 수정

[수정 요약과 남은 한계](PROJECT_SUMMARY.md)를 확인하세요. 교육과정 불일치 차단, 미해석 행 검토, 한글 성적·평점 열 처리, 공식 요건 확인 대기 표시를 추가했습니다. 회귀·화면 테스트는 총 21개입니다. 실제 성적표 정확도 및 공식 대체과목 인정은 추가 검증이 필요합니다.

## 실행

Mac에서는 `run.command`를 실행한 뒤 http://localhost:8503 에 접속하세요. 첫 실행에는 패키지와 OCR 모델을 내려받을 인터넷 연결이 필요합니다. Python 3.11 이상을 권장합니다.

```bash
cd graduation-photo-ai
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python tools/prepare_ocr.py
.venv/bin/python -m streamlit run app.py --server.port 8503 --server.address 127.0.0.1
```

## 사용 순서

1. 입학연도(2022~2025)와 트랙(인공지능빅데이터, 정보통신보안, 스마트미디어)을 선택합니다.
2. 성적표 사진을 올리고 문자 인식을 실행합니다. 사진은 과목명·학점·성적이 한 줄로 보이도록 잘라 업로드하면 좋습니다. 사진 여러 장을 함께 올릴 수 있습니다.
3. 추출된 행을 원문과 대조해 학점·이수구분·성적을 수정하고 확인 칸을 선택합니다. 자동 추출하지 못한 과목과 교양 과목도 표에 추가합니다.
4. 학과에서 의무 이수라고 확인한 과목을 지정한 후 사전 점검합니다.
5. 항목별 부족 학점, 지정 과목 미이수, 중복·F 제외 내역을 확인합니다. 검토 내역 CSV와 결과 JSON을 내려받을 수 있습니다.

OCR 결과는 원문과 신뢰도를 제공합니다. 낮은 신뢰도뿐 아니라 모든 OCR 행을 확인해야 계산합니다. 복잡한 다단 성적표, 학점 옆 숫자 코드, 학교별 성적표 양식은 자동 구조화에 실패할 수 있으며 원문 텍스트나 CSV로 보완할 수 있습니다. 미해석 행은 별도 표에 표시되며 누락 과목을 추가했다고 확인해야 점검할 수 있습니다. 이미지에서 학점이나 성적을 찾지 못하면 통과 성적을 만들어 넣지 않습니다. 표 이름만 비슷한 과목을 대체 인정하지 않습니다.

## 교육과정 근거 및 적용 범위

- `reference/curriculum-2011-2025.pdf`: 사용자 제공 원문 전체.
- `data/curriculum.json`: 12개 연도·트랙 프로필, 각 과목 원문 페이지, 추출 방식, 경고, 원문 SHA-256 및 텍스트.
- 2022(원문 20쪽)는 스캔 이미지라 육안 확인 후 수기 전사했습니다. 원문의 멀콘·정보·인공을 각각 스마트미디어·정보통신보안·인공지능빅데이터 명칭에 대응했습니다. 트랙 명칭 대응과 과목별 이수 인정은 학과 확인이 필요합니다.
- 2022: 총 127, 교양 36(12/6/15/3), 학부공통+전공필수 54, 전공선택 21, 전공합계 75.
- 2023: 총 127, 교양 36(12/6/15/3), 전공필수 12, 전공선택 24, 전공합계 36, 전공심화 선택 21.
- 2024~2025: 총 127, 교양 34(10/6/15/3), 전공필수 12, 전공선택 24, 전공합계 36, 전공심화 선택 21.
- 2022 자율선택 16학점 표기는 총학점 잔여분으로 보고 별도 최소조건으로 단정하지 않았습니다. 2023 이후 자율선택도 잔여학점으로 표기되어 있습니다.
- 전공심화는 선택 경로이며 기본 필수조건으로 강제하지 않습니다. 선택 시 별도 21학점을 검사합니다. 전공심화는 전공선택에 포함한다는 가정을 화면과 결과에 명시했습니다. 총학점에는 한 번만 반영합니다.
- 원문 상단의 전공필수 최소학점과 하단 필수 과목 목록 총학점이 일치하지 않습니다. 목록 전체를 의무 이수로 단정하지 않고, 사용자가 학과 확인을 거쳐 지정한 과목만 별도 의무 검사합니다.
- 2024~2025 정보통신보안 페이지의 이름 없는 3학점 셀은 제외하고 경고합니다. '네크워크' 등 원문 오탈자는 임의로 정정·대체하지 않았습니다.
- 원문 19쪽 명칭변경표는 ~2021학년도 대상 및 특정 학번 예외가 있어 2022~2025에 자동 적용하지 않았습니다.
- 학칙·졸업시험·논문·봉사·인증·교양 의무 과목·영역별 조건·복수전공·편입·학적 변동·폐강 대체 인정 등은 이 자료만으로 확정할 수 없습니다. 앱 결과는 공식 졸업 판정이 아닙니다.

교육과정 데이터를 다시 만들려면:

```bash
.venv/bin/python tools/import_curriculum.py reference/curriculum-2011-2025.pdf
```

## 구성

- `app.py`: 업로드, OCR 검토 표, 기준 열람, 점검·내보내기 화면
- `graduation/ocr.py`: PyTorch / EasyOCR 한국어·영어 모델, 회전 보정, 좌표 기반 행 구성
- `graduation/engine.py`: 행 후보 추출 및 결정적 학점 계산, 성적·중복·검토 상태 검사
- `tests/test_engine.py`: 연도별 기준, OCR 후보, 중복·F·불확실 입력·전공심화 합산 회귀 검사

`data/sample-transcript.png`는 학생 개인정보가 없는 가상 성적표로, `.venv/bin/python tools/smoke_ocr.py`로 실제 OCR을 시험할 수 있습니다.

새로 모델을 학습한 시스템이 아니라, 사전학습된 CRAFT/CRNN 계열 OCR 모델을 활용합니다. 학점 비교는 규칙으로 계산하며 AI 추론으로 졸업 조건을 생성하지 않습니다. API 키나 외부 LLM은 사용하지 않습니다. EasyOCR 공식 자료: https://github.com/JaidedAI/EasyOCR

## 검증

```bash
.venv/bin/python -m unittest discover -s tests -v
```

학생 사진과 성적표는 파일에 영구 저장하지 않으며 앱 세션 메모리에서 처리합니다. OCR 모델만 `.models/`에 저장됩니다. 공유 서비스용 인증·권한·영구 저장은 포함하지 않습니다.

### 이번 실행에서 확인한 결과

- 초기 계산 및 화면 흐름 검사 13개 통과. 2026-10-29 입력 검증 개선 후 21개 통과.
- 한국어 OCR 모델 다운로드 및 실제 추론 실행 완료.
- 가상 성적표의 4개 이수 행을 추출했지만, 과목명은 2/4개를 정확히 인식했습니다. B0를 BO로 읽는 오류도 있어 무인 자동 판정에 사용할 수준으로 검증된 것은 아닙니다. 모든 행을 원문과 대조해야 합니다.
- 검토 단계에서 오류를 수정한 뒤 취득 9학점, F 제외 계산을 확인했습니다 (`data/ocr-smoke-result.txt`).
- 실제 학교 성적표 사진의 인식률과 다양한 양식은 아직 측정하지 않았습니다.
