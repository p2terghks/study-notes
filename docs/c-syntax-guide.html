STEP 01

시작과 컴파일

C는 타입과 메모리 사용을 명시하며 프로그램을 작성하는 언어입니다. 이 가이드는 C17 기준의 기본 문법을 사용합니다.

c
#include <stdio.h>

int main(void) {
    printf("Hello, C!\n");
    return 0;
}
bash
cc -std=c17 -Wall -Wextra -pedantic hello.c -o hello
./hello

Clang 또는 GCC가 설치된 macOS/Linux 터미널 기준입니다. Windows에서는 C 컴파일러와 개발 환경을 먼저 준비해야 합니다.

부분 의미
#include <stdio.h> 표준 입출력 함수 선언 사용
int main(void) 입력 매개변수가 없는 프로그램 시작 함수
; 문장 끝
{ ... } 코드 블록
return 0 정상 종료 상태

짧은 코드는 문법 설명용 발췌입니다. printf에는 stdio.h 등 필요한 헤더가 있어야 합니다. 마지막의 전체 프로그램은 헤더와 main을 모두 포함합니다.

변수·자료형·초기화

c
int age = 20;
double height = 175.5;
char grade = 'A';
const int max_score = 100;
타입 의미 출력 예
int 정수 %d
double 실수 %f
char 문자 코드 값을 담는 정수 타입 %c
size_t 크기와 개수를 표현하는 부호 없는 정수 타입 %zu

C17에서 논리값을 쓰려면 #include <stdbool.h> 뒤 bool, true, false를 사용합니다.

c
printf("age=%d, height=%.1f\n", age, height);

지역 변수는 초기화하지 않으면 안전하게 읽을 수 없습니다. 선언할 때 초기값을 넣으세요. int가 항상 4바이트라고 가정하지 말고 필요하면 sizeof로 확인합니다. const는 해당 이름을 통한 값 변경을 제한합니다.

STEP 03

연산자와 타입 변환

c
int a = 7;
int b = 2;
printf("%d\n", a / b);          // 3
printf("%.1f\n", (double)a / b); // 3.5
printf("%d\n", a % b);          // 1
목적 문법
비교 ==, !=, <, <=, >, >=
논리 &&, `
누적 +=, -=, ++, --
비트 연산 &, `

정수끼리 나누면 소수 부분이 0 방향으로 버려집니다. (double)a는 a를 실수로 변환한 값입니다. 0으로 나누지 않아야 합니다.

^는 거듭제곱이 아니라 비트 XOR입니다. 부호 있는 정수의 표현 범위를 넘기는 연산은 정의되지 않은 동작이므로 큰 값 계산도 주의해야 합니다.

STEP 04

입력과 출력

c
int age = 0;
printf("Age: ");

if (scanf("%d", &age) != 1) {
    fprintf(stderr, "Invalid input\n");
    return 1;
}

printf("Age: %d\n", age);
  1. scanf는 값을 저장할 위치가 필요합니다.
  2. &age는 age의 주소입니다.
  3. 반환값 1은 항목 하나가 정상 변환되었다는 뜻입니다.
  4. printf는 값을 받아 출력하므로 age를 그대로 전달합니다.
자료형 printf scanf
int %d %d와 int 주소
double %f %lf와 double 주소

위 scanf 예제는 표현 가능한 정수 입력을 가정하는 기초 설명입니다. 너무 큰 숫자까지 견고하게 검사하려면 fgets로 한 줄을 읽고 strtol로 변환한 뒤 범위와 남은 문자를 검사합니다. 전체 실습에서는 이 방식을 사용합니다.

STEP 05

조건문과 switch

c
int score = 85;
if (score >= 90) {
    puts("A");
} else if (score >= 80) {
    puts("B");
} else {
    puts("Try again");
}

C의 조건식은 0이면 거짓이고 0이 아니면 참입니다. if (score = 90)은 비교가 아니라 대입이므로 의도치 않은 결과를 만듭니다.

c
int menu = 1;
switch (menu) {
    case 1:
        puts("Start");
        break;
    case 2:
        puts("Stop");
        break;
    default:
        puts("Unknown");
}

switch는 정수형 값에 따른 분기에 사용합니다. break가 없으면 다음 case의 문장도 이어서 실행될 수 있습니다.

STEP 06

반복문

c
for (int i = 0; i < 3; i++) {
    printf("%d\n", i);  // 0, 1, 2
}

int count = 0;
while (count < 3) {
    count++;
}
for 구성 역할
int i = 0 한 번 초기화
i < 3 매 회차 실행 전 조건 검사
i++ 본문 실행 후 증가

break는 반복문을 끝내고 continue는 다음 회차로 넘어갑니다. do-while은 조건 검사 전에 본문을 한 번 실행합니다.

c
int n = 0;
do {
    n++;
} while (n < 3);

do-while 마지막의 세미콜론을 빠뜨리지 마세요.

STEP 07

함수와 값 전달

c
int add(int a, int b) {
    return a + b;
}

int main(void) {
    int result = add(3, 5);
    return result == 8 ? 0 : 1;
}
부분 역할
앞의 int 반환 타입
int a, int b 매개변수 타입과 이름
return 결과 반환
void 반환값이 없거나 매개변수가 없음을 명시

C에서는 인수 값이 복사되어 전달됩니다. 함수 안에서 매개변수를 바꿔도 호출한 쪽의 정수 변수는 바뀌지 않습니다. 원본을 변경하려면 주소를 전달합니다.

함수를 호출하는 위치보다 정의가 뒤에 있다면 int add(int a, int b); 같은 선언을 먼저 둡니다.

STEP 08

배열과 문자열

c
int scores[] = {80, 90, 100};
size_t count = sizeof scores / sizeof scores[0];
for (size_t i = 0; i < count; i++) {
    printf("%d\n", scores[i]);
}

char name[] = "Minsu";
printf("%s\n", name);

배열 인덱스는 0부터 시작합니다. scores[3]은 위 배열 범위를 벗어납니다. C는 일반적인 배열 접근의 범위를 자동 검사하지 않습니다.

C 문자열은 끝에 \0 문자가 있는 char 배열입니다. "Minsu"를 저장하려면 마지막 널 문자까지 6칸이 필요합니다.

c
char line[32];
if (fgets(line, sizeof line, stdin) != NULL) {
    printf("%s", line);
}

fgets는 버퍼 크기를 받아 공간을 넘겨 쓰지 않도록 읽습니다. 줄바꿈이 버퍼에 들어올 수 있고, 너무 긴 줄은 일부가 다음 입력에 남을 수 있습니다.

배열 매개변수는 함수에서 포인터로 조정됩니다. 함수 안의 sizeof로 호출자 배열 길이를 구할 수 없으므로 길이도 함께 전달합니다. 문자열 비교는 == 대신 string.h의 strcmp를 사용합니다.

포인터 — 주소와 값

c
int value = 10;
int *pointer = &value;

*pointer = 20;
printf("%d\n", value);  // 20
text
pointer ──주소──▶ value가 있는 메모리
                  값: 20
문법 의미
&value value의 주소
int *pointer int를 가리킬 포인터 선언
*pointer 가리키는 위치의 값에 접근
NULL 유효한 객체를 가리키지 않는 포인터 값
c
void increase(int *value) {
    if (value != NULL) {
        (*value)++;
    }
}

호출자가 increase(&count)로 count의 주소를 주면 함수가 원본을 바꿀 수 있습니다. NULL 검사만으로 이미 해제된 메모리 같은 모든 잘못된 포인터를 알아낼 수 있는 것은 아닙니다.

구조체 — 관련 값 묶기

c
struct Student {
    char name[32];
    int score;
};

struct Student student = {"Minsu", 85};
struct Student *pointer = &student;

printf("%s: %d\n", student.name, student.score);
printf("%d\n", pointer->score);
접근 대상 문법
구조체 값 student.score
구조체 포인터 pointer->score

pointer->score는 (*pointer).score와 같습니다. 구조체는 관련된 데이터를 하나로 묶습니다. 배열과 구조체를 조합하면 여러 학생 정보를 표현할 수 있습니다.

STEP 11

동적 메모리와 파일

필요한 크기의 메모리를 실행 중에 확보할 수 있습니다.

c
#include <stdlib.h>

int *scores = malloc(3 * sizeof *scores);
if (scores == NULL) {
    return 1;
}
scores[0] = 80;
scores[1] = 90;
scores[2] = 100;
free(scores);
scores = NULL;

위 코드는 main 내부에 들어가는 예시이며 include는 파일 상단에 둡니다. malloc의 메모리는 초기화되지 않습니다. 읽기 전에 값을 넣고, 사용 후 정확히 한 번 해제합니다. 해제 후 접근은 금지입니다.

c
FILE *file = fopen("memo.txt", "w");
if (file == NULL) {
    return 1;
}
int write_failed = fprintf(file, "Hello\n") < 0;
int close_failed = fclose(file) == EOF;
if (write_failed || close_failed) {
    return 1;
}

파일 예시는 stdio.h와 main 안에서 사용합니다. w는 기존 파일 내용을 덮어씁니다. 파일도 열기에 성공했으면 닫아야 합니다.

실수 점검과 다음 단계

  • 문장 끝의 세미콜론을 확인한다.
  • 모든 지역 변수에 초기값을 넣는다.
  • printf와 scanf의 형식 지정자를 타입과 맞춘다.
  • 배열 범위를 벗어나지 않는다.
  • NULL이나 해제된 포인터를 역참조하지 않는다.
  • 경고 옵션을 켜고 컴파일러 경고를 읽는다.

C의 정의되지 않은 동작은 단순히 오류 메시지를 보여준다는 뜻이 아닙니다. 프로그램 결과를 보장할 수 없게 되므로 범위와 수명 규칙을 지켜야 합니다.

성적 집계 — 전체 코드

0~100점 정수 세 개를 입력받고 평균과 합격자 수를 출력합니다. 합격 기준은 60점입니다. 영어 출력은 터미널 환경 차이를 줄이기 위해 사용합니다.

소스 파일 보기 · 파일명: scores.c

c
#include <ctype.h>
#include <errno.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

// 성공하면 1, 입력이 끝났으면 0을 반환합니다.
static int read_score(size_t index, int *result) {
    char line[128];
    for (;;) {
        printf("Score %zu: ", index);
        fflush(stdout);
        if (fgets(line, sizeof line, stdin) == NULL) {
            return 0;
        }
        // 버퍼보다 긴 줄은 남은 내용까지 버리고 다시 입력받습니다.
        if (strchr(line, '\n') == NULL && !feof(stdin)) {
            int ch;
            while ((ch = getchar()) != '\n' && ch != EOF) {
            }
            puts("Input is too long.");
            continue;
        }
        char *end = NULL;
        errno = 0;
        long value = strtol(line, &end, 10);
        int has_number = end != line;
        while (isspace((unsigned char)*end)) {
            ++end;
        }
        if (!has_number || errno == ERANGE || *end != '\0'
                || value < 0 || value > 100) {
            puts("Enter an integer from 0 to 100.");
            continue;
        }
        *result = (int)value;
        return 1;
    }
}

int main(void) {
    int scores[3] = {0};
    size_t count = sizeof scores / sizeof scores[0];
    int total = 0;
    int passed = 0;
    for (size_t i = 0; i < count; ++i) {
        if (!read_score(i + 1, &scores[i])) {
            fputs("Input ended before all scores were entered.\n", stderr);
            return 1;
        }
        total += scores[i];
        if (scores[i] >= 60) {
            ++passed;
        }
    }
    printf("Average: %.2f\n", (double)total / count);
    printf("Passed: %d\n", passed);
    return 0;
}
실행 방법과 예상 결과

소스 파일이 있는 examples/languages 폴더의 터미널에서 실행하세요. C와 C++ 예제는 각각 컴파일하면 실행 파일 scores가 교체됩니다.

bash
cc -std=c17 -Wall -Wextra -pedantic scores.c -o scores
./scores

점수를 한 줄에 하나씩 입력합니다.

text
80
90
50

예상 결과:

text
Average: 73.33
Passed: 2

직접 확인하기

입력 기대 결과
80, 90, 50 평균 73.33, 합격 2명
0, 60, 100 평균 53.33, 합격 2명
abc 또는 101 안내 메시지 후 다시 입력
세 점수 전에 입력 종료 종료 코드 1과 안내 메시지
코드 읽는 순서
  1. main에서 세 점수를 담을 공간을 준비합니다.
  2. 입력 함수가 문자열을 정수로 변환하고 범위를 검사합니다.
  3. 반복문에서 정상 점수를 저장합니다.
  4. 전체 점수의 합과 60점 이상인 개수를 계산합니다.
  5. 실수 나눗셈으로 평균을 구하고 출력합니다.

read_score는 포인터 result를 통해 호출자의 변수에 값을 저장합니다. fgets로 한 줄을 읽고 strtol로 정수 변환을 시도합니다. end로 숫자 뒤에 남은 문자를 확인하고 errno로 변환 범위 오류를 검사합니다. isspace는 공백 여부를 확인하며 unsigned char로 변환해 유효한 인수 범위를 지킵니다. static 함수는 이 소스 파일 안에서만 연결되는 함수입니다.

파일 저장 기능은 포함하지 않습니다. 프로그램을 종료하면 점수는 사라집니다. 먼저 합격 기준을 바꿔 보고, 다음에는 입력받을 학생 수를 늘려 보세요.
