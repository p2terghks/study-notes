1. 챗봇의 역할과 범위

로그인한 학생의 강의·신청 내역·학적 정보를 받아 질문을 분류하고, 시간표·수업 추천·잔여 좌석·충돌·졸업요건을 안내합니다. 기본은 Python 규칙형입니다. FastAPI는 선택형 내부 서비스이며 ONNX·TensorFlow 모델은 별도 준비가 필요합니다. OpenAI API와 Streamlit은 사용하지 않습니다.

현재 React의 수강 도우미가 Spring 상담 API와 연결되어 있습니다. Python은 추천과 답변을 만들며, 추천 카드의 신청·장바구니 동작은 기존 Spring API가 최종 검증합니다.

3.2. extract_filters() — 질문에서 요일과 시간 조건을 추출

src/main/resources/python/advisor.py · 15행 · 함수 전체

  • 입력: message는 사용자가 쓴 질문 문자열입니다.
  • 처리: 공백을 지우고 제외 요일·포함 요일을 찾습니다. 오전은 09:00~12:00, 오후는 12:00~18:00를 기본값으로 두고 명시적인 시각이 있으면 범위를 조정합니다. 시작이 종료보다 늦거나 같으면 ValueError를 발생시킵니다.
  • 반환: days·excludedDays·start·end를 반환합니다. 요일은 월=0~금=4이며 시각은 자정 이후 분 단위입니다.
  • 예시·주의: extract_filters('화요일 오후 수업 추천') → {'days': [1], 'excludedDays': [], 'start': 720, 'end': 1080}

def extract_filters(message):
    """명시적인 요일·오전/오후·시각 조건을 추출한다. 복잡한 발화는 추측하지 않는다."""
    text = re.sub(r'\s+', '', message.lower())
    excluded = [i for i, d in enumerate(DAYS)
                if re.search(d + r'(?:요일)?(?:은|는|에는)?(?:공강|빼|제외|피하|쉬)', text)]
    included = [i for i, d in enumerate(DAYS) if d + '요일' in text and i not in excluded]
    after, before = (720, 1080) if '오후' in text else (540, 720) if '오전' in text else (0, 1440)
    times = list(re.finditer(r'(\d{1,2})시(?:(\d{1,2})분)?', text))
    def minute(m):
        h, n = int(m[1]), int(m[2] or 0)
        if not 0 <= h <= 23 or not 0 <= n <= 59:
            raise ValueError('시각은 0~23시, 분은 0~59분으로 입력해주세요.')
        if '오후' in text and h < 12: h += 12
        if '오전' in text and h == 12: h = 0
        return h * 60 + n
    if len(times) == 2:
        after, before = minute(times[0]), minute(times[1])
    elif len(times) == 1:
        value = minute(times[0])
        if any(w in text for w in ('이전', '전까지')): before = value
        else: after = value
    if after >= before: raise ValueError('시작 시각은 종료 시각보다 빨라야 해요.')
    return dict(days=included, excludedDays=excluded, start=after, end=before)

3.4. matches_filters() — 강의의 모든 수업 시간이 조건에 맞는지 검사

src/main/resources/python/advisor.py · 40행 · 함수 전체

  • 입력: course는 강의 dict, filters는 extract_filters의 반환값입니다.
  • 처리: 수업 시간이 비어 있으면 거부합니다. 각 수업의 요일이 허용되고 제외 요일이 아니며 시작·종료가 요청 범위 안인지 all()로 검사합니다.
  • 반환: 조건을 모두 만족하면 True, 하나라도 어기면 False입니다.
  • 예시·주의: 화요일 13~15시 강의는 화요일 오후 조건에 맞지만, 같은 강의에 수요일 수업이 추가되면 화요일 한정 조건에서는 제외됩니다.
해당 함수 코드 보기 · 접기
PYTHON · 원본 발췌
def matches_filters(course, filters):
    return bool(course['meetings']) and all(
        (not filters['days'] or m['day'] in filters['days'])
        and m['day'] not in filters['excludedDays']
        and m['start'] >= filters['start'] and m['end'] <= filters['end']
        for m in course['meetings'])

3.6. unavailable() — 신청할 수 없는 이유를 계산

src/main/resources/python/advisor.py · 60행 · 함수 전체

  • 입력: course는 검사할 강의입니다. 기존 신청 ID·현재 학점·최대 학점·신청 강의 시간은 reply의 변수를 공유합니다.
  • 처리: 이미 신청 → 정원 마감 → 학점 초과 → 시간 충돌 순서로 검사하고 첫 번째 사유만 반환합니다. 같은 요일의 두 시간 구간이 실제 겹치는지 확인합니다.

  • 예시·주의: 기존 수업이 10:00~11:00일 때 10:30 시작 수업은 충돌, 11:00 시작 수업은 연속 수업으로 허용됩니다.

def unavailable(course):
    if course['id'] in state['enrolledIds']:
        return '이미 신청한 강의예요.'
    if course['enrolled'] >= course['capacity']:
        return '현재 정원이 마감됐어요.'
    if credits + course['credits'] > student['maxCredits']:
        return '현재 남은 신청 학점을 초과해요.'
    if any(a['day'] == b['day'] and a['start'] < b['end'] and b['start'] < a['end']
           for c in enrolled for a in c['meetings'] for b in course['meetings']):
        return '이미 신청한 강의와 시간이 겹쳐요.'
    return None

def meeting_text(course):
    def clock(minutes):
        return f'{minutes // 60:02d}:{minutes % 60:02d}'
    return ', '.join(f"{DAYS[m['day']]} {clock(m['start'])}–{clock(m['end'])}" for m in course['meetings'])

def encode(self, texts):
    import numpy as np
    tokens = self.tokenizer(texts, padding=True, truncation=True, max_length=256, return_tensors='np')
    inputs = {i.name: tokens[i.name].astype(np.int64) for i in self.session.get_inputs()}
    embeddings = self.session.run(['embeddings'], inputs)[0]
    if embeddings.ndim != 2 or embeddings.shape[0] != len(texts) or not np.isfinite(embeddings).all():
        raise ValueError('Invalid embedding output')
    return embeddings

3.17. SemanticRanker.rank() — 질문과 강의계획서의 유사도로 순위를 계산

ai-engine/app/semantic.py · 36행 · 함수 전체

  • 반환: 강의 ID 순서 목록과 모드 문자열의 튜플입니다. 모드는 rules·rules-missing-syllabi·onnx-tensorflow 중 하나입니다.
  • 예시·주의: 반환된 ID 순서를 호출부가 실제 적용해야 화면 추천 순서에 반영됩니다. 아래 현재 코드의 적용 범위를 함께 확인하세요.
해당 함수 코드 보기 · 접기
PYTHON · 원본 발췌
def rank(self, query, courses):
    if not self.enabled:
        return [c['id'] for c in courses], 'rules'
    # 일부 계획서만 등록된 상태에서 나머지 과목을 임의 의미 벡터로 만들지 않는다.
    if any(not isinstance(self.syllabi.get(c['code']), str) or not self.syllabi[c['code']].strip() for c in courses):
        return [c['id'] for c in courses], 'rules-missing-syllabi'
    texts = [f"{c['name']}\n{self.syllabi[c['code']]}" for c in courses]
    key = hashlib.sha256(json.dumps(texts, ensure_ascii=False).encode()).hexdigest()
    with self.lock:
        if key not in self.cache:
            if len(self.cache) >= 16: self.cache.clear()
            self.cache[key] = self.encode(texts)
        matrix = self.cache[key]
    tf = self.tf
    # 같은 ONNX 모델 공간의 벡터끼리 정규화 후 행렬곱: 코사인 유사도.
    q = tf.math.l2_normalize(tf.convert_to_tensor(self.encode([query])), axis=1)
    corpus = tf.math.l2_normalize(tf.convert_to_tensor(matrix), axis=1)
    scores = tf.linalg.matmul(q, corpus, transpose_b=True)[0]
    order = tf.argsort(scores, direction='DESCENDING', stable=True).numpy().tolist()
    return [courses[i]['id'] for i in order], 'onnx-tensorflow'

PYTHON
"""학사 상담 엔진. 표준 입력 JSON → 표준 출력 JSON (Python 3.10+)."""
import json
import re
import sys

DAYS = '월화수목금'
SUGGESTIONS = ['졸업요건 알려줘', '수업 추천해줘', '내 시간표 알려줘']


def answer(topic, message, points=(), recommendations=(), sources=(), suggestions=SUGGESTIONS):
    return dict(topic=topic, message=message, points=list(points),
                recommendations=list(recommendations), sources=list(sources), suggestions=list(suggestions))


def extract_filters(message):
    """명시적인 요일·오전/오후·시각 조건을 추출한다. 복잡한 발화는 추측하지 않는다."""
    text = re.sub(r'\s+', '', message.lower())
    excluded = [i for i, d in enumerate(DAYS)
                if re.search(d + r'(?:요일)?(?:은|는|에는)?(?:공강|빼|제외|피하|쉬)', text)]
    included = [i for i, d in enumerate(DAYS) if d + '요일' in text and i not in excluded]
    after, before = (720, 1080) if '오후' in text else (540, 720) if '오전' in text else (0, 1440)
    times = list(re.finditer(r'(\d{1,2})시(?:(\d{1,2})분)?', text))
    def minute(m):
        h, n = int(m[1]), int(m[2] or 0)
        if not 0 <= h <= 23 or not 0 <= n <= 59:
            raise ValueError('시각은 0~23시, 분은 0~59분으로 입력해주세요.')
        if '오후' in text and h < 12: h += 12
        if '오전' in text and h == 12: h = 0
        return h * 60 + n
    if len(times) == 2:
        after, before = minute(times[0]), minute(times[1])
    elif len(times) == 1:
        value = minute(times[0])
        if any(w in text for w in ('이전', '전까지')): before = value
        else: after = value
    if after >= before: raise ValueError('시작 시각은 종료 시각보다 빨라야 해요.')
    return dict(days=included, excludedDays=excluded, start=after, end=before)


def matches_filters(course, filters):
    return bool(course['meetings']) and all(
        (not filters['days'] or m['day'] in filters['days'])
        and m['day'] not in filters['excludedDays']
        and m['start'] >= filters['start'] and m['end'] <= filters['end']
        for m in course['meetings'])

각 추천은 현재 시간표에 대한 개별 후보입니다. 후보끼리 겹칠 수 있으며 최종 신청 가능 여부는 신청 API가 다시 검사합니다. 실제 이수 성적표가 없어 졸업 충족 여부를 판정하지 않습니다.

def answer(topic, message, points=(), recommendations=(), sources=(), suggestions=SUGGESTIONS):
    return dict(topic=topic, message=message, points=list(points),
                recommendations=list(recommendations), sources=list(sources), suggestions=list(suggestions))


def extract_filters(message):
    """명시적인 요일·오전/오후·시각 조건을 추출한다. 복잡한 발화는 추측하지 않는다."""
    text = re.sub(r'\s+', '', message.lower())
    excluded = [i for i, d in enumerate(DAYS)
                if re.search(d + r'(?:요일)?(?:은|는|에는)?(?:공강|빼|제외|피하|쉬)', text)]
    included = [i for i, d in enumerate(DAYS) if d + '요일' in text and i not in excluded]
    after, before = (720, 1080) if '오후' in text else (540, 720) if '오전' in text else (0, 1440)
    times = list(re.finditer(r'(\d{1,2})시(?:(\d{1,2})분)?', text))
    def minute(m):
        h, n = int(m[1]), int(m[2] or 0)
        if not 0 <= h <= 23 or not 0 <= n <= 59:
            raise ValueError('시각은 0~23시, 분은 0~59분으로 입력해주세요.')
        if '오후' in text and h < 12: h += 12
        if '오전' in text and h == 12: h = 0
        return h * 60 + n
    if len(times) == 2:
        after, before = minute(times[0]), minute(times[1])
    elif len(times) == 1:
        value = minute(times[0])
        if any(w in text for w in ('이전', '전까지')): before = value
        else: after = value
    if after >= before: raise ValueError('시작 시각은 종료 시각보다 빨라야 해요.')
    return dict(days=included, excludedDays=excluded, start=after, end=before)


def matches_filters(course, filters):
    return bool(course['meetings']) and all(
        (not filters['days'] or m['day'] in filters['days'])
        and m['day'] not in filters['excludedDays']
        and m['start'] >= filters['start'] and m['end'] <= filters['end']
        for m in course['meetings'])

class ChatInput(BaseModel):
    state: dict
    profile: dict
    message: str = Field(min_length=1, max_length=1000)
    previousTopic: str | None = Field(default=None, max_length=30)
    policy: dict | None = None


@app.get('/health')
def health():
    return {'status': 'UP', 'model': 'onnx-tensorflow' if ranker.enabled else 'rules'}


@app.post('/chat')
def chat(payload: ChatInput, x_engine_key: str = Header(default='')):
    if not secrets.compare_digest(key, x_engine_key):
        raise HTTPException(401, 'Unauthorized engine request')
    if len(payload.state.get('courses', [])) > 2000:
        raise HTTPException(413, 'Course catalog is too large')
    if not slots.acquire(blocking=False):
        raise HTTPException(503, 'Engine capacity exceeded')
    try:
        return rules.reply(payload.model_dump(), ranker.rank if ranker.enabled else None)
    finally:
        slots.release()

        self.session = ort.InferenceSession(os.environ['ONNX_MODEL_PATH'], providers=['CPUExecutionProvider'])
        self.tokenizer = AutoTokenizer.from_pretrained(os.environ['TOKENIZER_PATH'], local_files_only=True)
        source = Path(os.environ['SYLLABI_PATH'])
        self.syllabi = json.loads(source.read_text(encoding='utf-8'))
        if not isinstance(self.syllabi, dict) or not self.syllabi:
            raise ValueError('SYLLABI_PATH must map course codes to actual syllabus text')

    def encode(self, texts):
        import numpy as np
        tokens = self.tokenizer(texts, padding=True, truncation=True, max_length=256, return_tensors='np')
        inputs = {i.name: tokens[i.name].astype(np.int64) for i in self.session.get_inputs()}
        embeddings = self.session.run(['embeddings'], inputs)[0]
        if embeddings.ndim != 2 or embeddings.shape[0] != len(texts) or not np.isfinite(embeddings).all():
            raise ValueError('Invalid embedding output')
        return embeddings

    def rank(self, query, courses):
        if not self.enabled:
            return [c['id'] for c in courses], 'rules'
        # 일부 계획서만 등록된 상태에서 나머지 과목을 임의 의미 벡터로 만들지 않는다.
        if any(not isinstance(self.syllabi.get(c['code']), str) or not self.syllabi[c['code']].strip() for c in courses):
            return [c['id'] for c in courses], 'rules-missing-syllabi'
        texts = [f"{c['name']}\n{self.syllabi[c['code']]}" for c in courses]
        key = hashlib.sha256(json.dumps(texts, ensure_ascii=False).encode()).hexdigest()
        with self.lock:
            if key not in self.cache:
                if len(self.cache) >= 16: self.cache.clear()
                self.cache[key] = self.encode(texts)
            matrix = self.cache[key]
        tf = self.tf
        # 같은 ONNX 모델 공간의 벡터끼리 정규화 후 행렬곱: 코사인 유사도.
        q = tf.math.l2_normalize(tf.convert_to_tensor(self.encode([query])), axis=1)
        corpus = tf.math.l2_normalize(tf.convert_to_tensor(matrix), axis=1)
        scores = tf.linalg.matmul(q, corpus, transpose_b=True)[0]
        order = tf.argsort(scores, direction='DESCENDING', stable=True).numpy().tolist()
        return [courses[i]['id'] for i in order], 'onnx-tensorflow'
