STEP 01

시작과 컴파일

C++은 타입·함수에 더해 클래스와 표준 라이브러리로 프로그램을 구성합니다. 이 가이드는 C++17 기준입니다.

cpp
#include <iostream>

int main() {
    std::cout << "Hello, C++!\n";
    return 0;
}
bash
c++ -std=c++17 -Wall -Wextra -pedantic hello.cpp -o hello
./hello

Clang 또는 GCC가 설치된 macOS/Linux 터미널 기준입니다. 파일 확장자는 .cpp입니다. std::는 표준 라이브러리의 이름 공간에 속한다는 뜻입니다.

C++은 단순히 C 문법에 class만 붙인 언어는 아닙니다. 처음부터 std::string, std::vector와 자동 자원 관리를 활용하세요. 짧은 코드는 문법 발췌이고 마지막 예제는 완전한 프로그램입니다.

STEP 02

변수·타입·auto·const

cpp
int age = 20;
double height = 175.5;
bool is_student = true;
char grade = 'A';
const int max_score = 100;
auto count = 3;  // int로 추론
문법 의미
int, double, bool, char 정수, 실수, 논리값, 문자
auto 초기값으로 타입을 컴파일 시 추론
const 해당 이름을 통해 값을 변경하지 않음
int value{}; 정수를 0으로 초기화

auto는 Python처럼 실행 중 타입이 바뀐다는 뜻이 아닙니다. 타입은 컴파일 시 정해집니다. 초기화되지 않은 지역 변수를 읽지 마세요.

cpp
int count{};
std::cout << count << '\n';  // 0

연산자와 형 변환

cpp
int a = 7;
int b = 2;
std::cout << a / b << '\n';                      // 3
std::cout << static_cast<double>(a) / b << '\n'; // 3.5
목적 문법
비교 ==, !=, <, <=, >, >=
논리 &&, `
증감 ++, --
나머지 %
명시적 수치 변환 static_cast<타입>(값)

정수 나눗셈은 소수 부분을 0 방향으로 버립니다. 정수 범위 초과와 0 나눗셈에 주의합니다. ^는 비트 XOR이며 거듭제곱이 아닙니다.

STEP 04

입출력과 std::string

cpp
#include <iostream>
#include <string>

int main() {
    std::string name;
    std::cout << "Name: ";
    if (!std::getline(std::cin, name)) {
        return 1;
    }
    std::cout << "Hello, " << name << '\n';
}
문법 역할
std::cout 표준 출력
std::cin 표준 입력
<< 출력 스트림에 값 전달
>> 입력 스트림에서 값 추출
std::getline 공백을 포함해 한 줄 읽기
std::string 문자열을 관리하는 타입
cpp
std::string title = "C++";
title += " study";
std::cout << title.size() << '\n';

std::string은 필요한 메모리를 관리합니다. size는 char 요소 수이므로 UTF-8 한글의 눈에 보이는 글자 수와 같지 않을 수 있습니다.

std::cin >> number 다음에 getline을 쓰면 남은 줄바꿈 때문에 빈 줄을 읽을 수 있습니다. 초보 단계에서는 입력 방식을 한 줄 읽기로 통일하면 이해하기 쉽습니다.

STEP 05

조건문과 반복문

cpp
int score = 85;
if (score >= 60) {
    std::cout << "PASS\n";
} else {
    std::cout << "FAIL\n";
}

for (int i = 0; i < 3; ++i) {
    std::cout << i << '\n';
}

while은 조건이 참인 동안 반복하고, break는 반복 종료, continue는 다음 회차로 이동합니다. switch로 정수나 enum 값에 따라 분기할 수도 있습니다.

범위 기반 for는 컨테이너를 읽기 편하게 순회합니다.

cpp
std::vector<int> scores{80, 90, 100};
for (int score : scores) {
    std::cout << score << '\n';
}

vector를 사용하려면 #include <vector>가 필요합니다.

STEP 06

함수와 오버로딩

cpp
int add(int a, int b) {
    return a + b;
}

double add(double a, double b) {
    return a + b;
}

같은 이름의 함수라도 매개변수 구성이 다르면 정의할 수 있습니다. 이를 오버로딩이라고 합니다. 반환 타입만 다른 것으로는 구분할 수 없습니다.

cpp
std::cout << add(2, 3) << '\n';       // 정수 버전
std::cout << add(2.5, 3.5) << '\n';   // 실수 버전

함수 선언은 호출 전에 보여야 합니다. main 뒤에 정의하려면 앞에 int add(int a, int b); 같은 선언을 둡니다.

STEP 07

참조와 포인터

cpp
void increase(int& value) {
    ++value;
}

int count = 10;
increase(count);  // count는 11

참조는 기존 객체의 다른 이름이라고 생각하면 됩니다. int& 매개변수는 원본을 변경할 수 있습니다.

전달 방식 선언 특징
값 int value 복사본 전달
참조 int& value 원본 접근·수정
const 참조 const std::string& text 복사 없이 읽기
포인터 int* pointer 주소 전달, nullptr 표현 가능
cpp
int value = 10;
int* pointer = &value;
if (pointer != nullptr) {
    *pointer = 20;
}

참조와 포인터 모두 대상의 수명이 끝난 뒤 사용하면 안 됩니다. 지역 변수의 참조나 주소를 반환하지 마세요.

STEP 08

vector와 map

cpp
#include <vector>
#include <map>
#include <string>

std::vector<int> scores{80, 90};
scores.push_back(100);
std::cout << scores.at(0) << '\n';

std::map<std::string, int> grades;
grades["Minsu"] = 85;
std::cout << grades.at("Minsu") << '\n';
컨테이너 역할
std::vector 크기를 바꿀 수 있는 연속된 요소 목록
std::map 키로 값을 조회하는 정렬된 연관 컨테이너
std::array 크기가 고정된 배열 래퍼

vector.at()은 범위를 벗어나면 예외를 던집니다. vector[index]는 일반적으로 범위를 검사하지 않습니다. map[key]는 키가 없으면 새 값을 삽입하므로 단순 존재 확인에는 find를 사용할 수 있습니다.

vector의 크기 변경으로 재할당이 일어나면 기존 요소를 가리키던 참조·포인터·반복자가 무효가 될 수 있습니다.

STEP 09

클래스와 생성자

cpp
#include <string>

class Student {
private:
    std::string name_;
    int score_;

public:
    Student(const std::string& name, int score)
        : name_(name), score_(score) {}

    bool isPassed() const {
        return score_ >= 60;
    }
};
cpp
Student student("Minsu", 85);
std::cout << student.isPassed() << '\n';  // 1
코드 의미
private 클래스 밖에서 직접 접근 제한
public 외부에서 사용 가능
Student(...) 생성자
: name_(name), score_(score) 멤버 초기화 목록
메서드 뒤 const 일반 데이터 멤버를 변경하지 않는 메서드

클래스 정의 끝에는 ;를 붙입니다. struct와 class는 기능 대부분이 같고 기본 접근 수준이 각각 public, private라는 차이가 있습니다.

STEP 10

메모리 수명과 RAII

객체 수명에 자원 관리를 연결하는 방식을 RAII라고 합니다.

std::string과 std::vector는 객체가 사라질 때 자신이 소유한 메모리를 정리합니다. 보통 직접 new/delete를 작성하지 않아도 됩니다.

cpp
#include <memory>

{
    auto value = std::make_unique<int>(42);
    std::cout << *value << '\n';
} // unique_ptr가 소멸하면서 소유한 int도 해제
도구 역할
std::vector 여러 값을 담는 메모리 관리
std::unique_ptr 한 소유자가 동적 객체 관리
소멸자 객체 수명 종료 때 실행

unique_ptr는 복사할 수 없고 필요하면 소유권을 이동합니다. 단순한 값은 우선 지역 변수로 만들고 동적 할당은 필요할 때 사용하세요.

STEP 11

템플릿·알고리즘·람다

cpp
template <typename T>
T larger(T a, T b) {
    return a > b ? a : b;
}

템플릿은 여러 타입에 적용할 코드를 표현합니다. larger(3, 5)에서는 T가 int로 추론됩니다.

cpp
#include <algorithm>
#include <vector>

std::vector<int> scores{80, 100, 90};
std::sort(scores.begin(), scores.end());

int passed = std::count_if(scores.begin(), scores.end(),
    [](int score) { return score >= 90; });
  • sort는 범위를 정렬합니다.
  • begin과 end는 시작과 마지막 다음 위치를 가리키는 반복자입니다.
  • [](int score) { ... }는 그 자리에서 만드는 함수인 람다입니다.
  • count_if는 조건을 만족하는 항목 수를 셉니다.

처음에는 반복문으로 같은 처리를 작성해 보고 표준 알고리즘으로 바꿔 보세요.

파일·예외·학습 점검

cpp
#include <fstream>
#include <string>

std::ifstream file("memo.txt");
if (!file) {
    std::cerr << "Cannot open file\n";
    return 1;
}
std::string line;
while (std::getline(file, line)) {
    std::cout << line << '\n';
}

위 코드는 main 안에서 사용하고 필요한 헤더는 파일 상단에 둡니다. 파일 스트림은 수명이 끝나면 닫힙니다. 기본 설정에서 파일 열기 실패는 보통 예외 대신 스트림 상태로 확인합니다.

cpp
try {
    std::cout << scores.at(99) << '\n';
} catch (const std::out_of_range& error) {
    std::cerr << error.what() << '\n';
}

두 번째 예시는 vector 변수 scores가 선언되어 있고 stdexcept 헤더를 포함한 문맥에서 사용합니다.

  • auto가 동적 타입이 아님을 안다.
  • 값·참조·const 참조를 구분한다.
  • 문자열은 string, 목록은 vector로 표현한다.
  • 생성자와 소멸자의 역할을 이해한다.
  • 객체 수명보다 오래 참조를 보관하지 않는다.

성적 집계 · 전체 실습

세 언어에서 같은 문제를 풀며 문법을 비교해 보세요. 점수 입력·평균·합격자 수를 다룹니다.

성적 집계 — 전체 코드

0~100점 정수 세 개를 입력받고 평균과 합격자 수를 출력합니다. 합격 기준은 60점입니다. 영어 출력은 터미널 환경 차이를 줄이기 위해 사용합니다.

소스 파일 보기 · 파일명: scores.cpp

cpp
#include <iomanip>
#include <iostream>
#include <sstream>
#include <string>
#include <vector>

// 성공하면 true, 입력이 끝났으면 false를 반환합니다.
bool readScore(int index, int& result) {
    std::string line;
    while (true) {
        std::cout << "Score " << index << ": ";
        if (!std::getline(std::cin, line)) {
            return false;
        }
        std::istringstream input(line);
        int value = 0;
        char extra = '\0';
        if (!(input >> value) || (input >> extra)
                || value < 0 || value > 100) {
            std::cout << "Enter an integer from 0 to 100.\n";
            continue;
        }
        result = value;
        return true;
    }
}

int main() {
    std::vector<int> scores;
    for (int index = 1; index <= 3; ++index) {
        int score = 0;
        if (!readScore(index, score)) {
            std::cerr << "Input ended before all scores were entered.\n";
            return 1;
        }
        scores.push_back(score);
    }
    int total = 0;
    int passed = 0;
    for (int score : scores) {
        total += score;
        if (score >= 60) {
            ++passed;
        }
    }
    double average = static_cast<double>(total) / scores.size();
    std::cout << std::fixed << std::setprecision(2);
    std::cout << "Average: " << average << '\n';
    std::cout << "Passed: " << passed << '\n';
}

bash

입력 기대 결과

코드 읽는 순서
  1. main에서 세 점수를 담을 공간을 준비합니다.
  2. 입력 함수가 문자열을 정수로 변환하고 범위를 검사합니다.
  3. 반복문에서 정상 점수를 저장합니다.
  4. 전체 점수의 합과 60점 이상인 개수를 계산합니다.
  5. 실수 나눗셈으로 평균을 구하고 출력합니다.

readScore는 참조 result로 원본에 값을 저장합니다. istringstream은 문자열을 입력 스트림처럼 읽습니다. 정수를 읽은 뒤 공백 이외의 추가 문자가 있으면 거부합니다. vector는 입력된 점수를 보관하고 범위 기반 for가 각 값을 순회합니다. fixed와 setprecision(2)는 소수점 이하 두 자리 출력을 지정합니다.

파일 저장 기능은 포함하지 않습니다. 프로그램을 종료하면 점수는 사라집니다. 먼저 합격 기준을 바꿔 보고, 다음에는 입력받을 학생 수를 늘려 보세요.
