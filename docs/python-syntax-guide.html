변수와 자료형

변수는 값을 가리키는 이름입니다. 타입을 미리 선언하지 않습니다.

python
name = "민수"        # str: 문자열
age = 20             # int: 정수
height = 175.5       # float: 실수
is_student = True    # bool: 참/거짓
result = None        # 아직 값이 없음

print(name, age)
print(type(age))     # <class 'int'>
문법 의미
= 오른쪽 값을 왼쪽 이름에 연결
== 값이 같은지 비교
True, False 첫 글자가 대문자인 논리값
None 값이 없음을 나타내는 특별한 값

같은 이름에 다른 타입의 값을 연결할 수 있지만, 한 변수의 의미와 타입을 일관되게 유지하면 읽기 쉽습니다. 정수는 메모리가 허용하는 범위에서 커질 수 있습니다.

클래스와 객체

python
class Student:
    def __init__(self, name, score):
        self.name = name
        self.score = score

    def is_passed(self):
        return self.score >= 60

student = Student("민수", 85)
print(student.name)         # 민수
print(student.is_passed())  # True
개념 코드
클래스: 설계도 Student
객체: 실제 값과 동작 student
초기화 메서드 __init__
현재 객체를 받는 매개변수 self
객체의 데이터 self.name

self는 인스턴스 메서드의 첫 매개변수로 관례적으로 사용하는 이름입니다. student.is_passed() 호출 시 해당 객체가 전달됩니다.

성적 집계 — 전체 코드

0~100점 정수 세 개를 입력받고 평균과 합격자 수를 출력합니다. 합격 기준은 60점입니다. 영어 출력은 터미널 환경 차이를 줄이기 위해 사용합니다.

소스 파일 보기 · 파일명: scores.py

python
"""세 점수를 입력받아 평균과 합격자 수를 출력합니다."""


def read_score(index):
    while True:
        try:
            score = int(input(f"Score {index}: "))
        except ValueError:
            print("Enter an integer from 0 to 100.")
            continue
        if 0 <= score <= 100:
            return score
        print("Enter an integer from 0 to 100.")


def main():
    scores = []
    try:
        for index in range(1, 4):
            scores.append(read_score(index))
    except EOFError:
        print("Input ended before all scores were entered.")
        return 1

    average = sum(scores) / len(scores)
    passed = sum(1 for score in scores if score >= 60)
    print(f"Average: {average:.2f}")
    print(f"Passed: {passed}")
    return 0


if __name__ == "__main__":
    raise SystemExit(main())

코드 읽는 순서
  1. main에서 세 점수를 담을 공간을 준비합니다.
  2. 입력 함수가 문자열을 정수로 변환하고 범위를 검사합니다.
  3. 반복문에서 정상 점수를 저장합니다.
  4. 전체 점수의 합과 60점 이상인 개수를 계산합니다.
  5. 실수 나눗셈으로 평균을 구하고 출력합니다.

read_score는 입력이 올바를 때까지 반복합니다. ValueError는 숫자 변환 실패, EOFError는 입력 종료를 나타냅니다. sum과 len으로 평균을 계산하고, 생성기 표현식으로 합격자를 셉니다. raise SystemExit(main())은 main의 반환값을 프로그램 종료 코드로 사용합니다.

파일 저장 기능은 포함하지 않습니다. 프로그램을 종료하면 점수는 사라집니다. 먼저 합격 기준을 바꿔 보고, 다음에는 입력받을 학생 수를 늘려 보세요.
